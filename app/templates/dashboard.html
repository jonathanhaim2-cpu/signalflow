חיבור חדש

שם שתזהו (למשל «אסטרטגיית ביטקוין») ולאן לשלוח. מדריך מצולם

ההתראות מגיעות לוואטסאפ שלכם — אותו מספר שמפעילים כאן. בלי מכשיר שני ובלי סריקת QR.

איך מוצאים את מספר הצ׳אט וקוד הבוט
  1. בטלגרם פותחים את BotFather ושולחים /newbot.
  2. נותנים שם לבוט. הוא מחזיר קוד ארוך — זה קוד הבוט. מעתיקים לכאן.
  3. פותחים את הבוט החדש ולוחצים Start, או מוסיפים אותו לקבוצה ושולחים הודעה.
  4. מספר הצ׳אט: אחרי הודעה לבוט, פותחים בדפדפן את הכתובת https://api.telegram.org/botהקוד/getUpdates ומחפשים את המספר ליד id.
איך מחלצים קישור מדיסקורד
  1. פותחים דיסקורד במחשב ונכנסים לשרת.
  2. עומדים על הערוץ, לוחצים על גלגל השיניים ליד שם הערוץ.
  3. בתפריט משמאל: Integrations → Webhooks.
  4. לוחצים New Webhook (או בוחרים אחד קיים).
  5. לוחצים Copy Webhook URL ומדביקים כאן למעלה.

הקישור צריך להיראות כך: https://discord.com/api/webhooks/…

איך מקבלים התראות לוואטסאפ שלכם (בלי סריקת QR)

זה שולח לטלפון שלכם — לא למכשיר שני, ולא צריך לסרוק כלום בדף הבית.

  1. בוואטסאפ מוסיפים איש קשר: +34 694 23 41 84 (אפשר לקרוא לו SignalFlow / CallMeBot).
  2. שולחים לו בדיוק: I allow callmebot to send me messages
  3. מחכים לתשובה עם קוד (APIKEY). אם אין תשובה תוך שתי דקות, מנסים שוב מחר (מגבלת הבוט).
  4. מדביקים כאן את המספר שלכם בפורמט 9725… ואת הקוד.
  5. לוחצים בדיקה מהירה — ההודעה צריכה להגיע לאותו וואטסאפ.
דרך מתקדמת — Green-API (לא חובה)

רק אם כבר משתמשים בזה: נכנסים ל־console.green-api.com → Create instance → ממתינים כשתי דקות → Get QR. בוואטסאפ: Linked devices → Link a device. אין QR בדף הבית של Green-API.
